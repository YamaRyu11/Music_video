Electronの実動作テストはLinuxの仮想画面を使用しています。
横・縦とも01 / 02へのスタイルDnDを操作し、MP4を書き出しました。
1440×900では設定パネル内部もスクロール不要。900×640では必要な設定パネルだけがスクロールします。
製品のWindowsパッケージではChromiumサンドボックスを有効にしています。

## 残る確認と制限

- **v0.8.0のWindows実機でのEXE起動は開発環境では未確認です。** ZIPが生成できたことと、Windows上で動作することは別です。
- Windows 11 x64で、ZIPの全展開・起動・ドラッグ＆ドロップ・日本語保存先・縦横出力・終了を確認してください。
- アプリは未署名。公開配布のリリース・署名・FFmpegの対応ソース配布はまだ行っていません。
- 現在の制限は250 MB・10分・30fps。長尺や多数チャンネルの音源でのメモリ・性能検証は未実施です。
- GPUエンコード、設定保存、60fpsは対象外です。背景画像のファイル読み込みは対応済みです。
- 背景画像は25 MB・32MP・各辺16384px以下。内部では長辺4096px以下へ縮小して使用します。

独立レイヤーの実出力は`npm run test:layers`、画像・結果は`.cache/layer-export-tests/`。

背景画像の実出力は`npm run test:bitmap`、画像・結果は`.cache/bitmap-export-tests/`。
新4種の実出力は`npm run test:generative`、画像・結果は`.cache/generative-export-tests/`。

ワイヤーフレーム4種の実出力は`npm run test:wireframes`、画像・結果は`.cache/wireframe-export-tests/`。

追加10種の実出力検査は`npm run test:new-styles`で再実行できます。結果・画像は`.cache/new-style-export-tests/`に保存します。

検証用のスクリーンショットはブラウザが`test-results/`、Electronが`.cache/desktop-test-results/`に出力します（Git対象外）。
テストはローカルで生成した音源を使い、ユーザーの音源・背景画像を外部に送信しません。
