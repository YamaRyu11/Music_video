## 実施した確認

Debian 13 / Node.js 24.19.0 / Electron 39.8.10 / Chromium 154で検証しました。

| 確認 | 結果 |
| --- | --- |
| TypeScript型チェック、本番ビルド | 成功 |
| 音声解析・IPC・FFmpeg統合テスト | 12件成功。6スタイル・合成・フォント設定の受理と不正な値の拒否も確認 |
| ブラウザ操作テスト | 3件成功。新スタイル・色調整・合成・文字編集をCanvasの画素比較で確認 |
| Electronの起動・preload・音源解析 | 成功 |
| WAV → 横1920×1080の実出力 | H.264 / AAC / yuv420p / 30fps / 240フレーム / 8秒 |
| 日本語名MP3 → 縦1080×1920の実出力 | H.264 / AAC / yuv420p / 30fps / 240フレーム / 8秒 |
| 出力MP4のフレームをデコード | 縦横とも成功 |
| 編集した文字のMP4出力 | 縦横とも90px・明朝・太字・斜体・ピンク色のタイトルを含む。デコード画像で指定色の文字画素を検出 |
| 合成を含む実出力 | 横はAurora＋Particle Flow（スクリーン）、縦はPulse Tunnel＋Silk Wave（加算） |
| 不透明度0%・合成解除 | 合成前のCanvasの画素と一致 |
| タイトル・アーティストの独立編集 | 片方のフォントサイズを変更しても他方を保持。表示切替・リセットも確認 |
| 出力キャンセル | 一時ファイル削除・既存出力の保持を確認 |
| 同じ時刻の描画 | 停止中にフレームを繰り返し描いても同一の画像 |
| Windows x64パッケージ | GitHub Actionsで作成。実行結果はリポジトリのActionsを参照 |

Electronの実動作テストはLinuxの仮想画面を使用しています。
製品のWindowsパッケージではChromiumサンドボックスを有効にしています。

## 残る確認と制限

- **v0.2.0のWindows実機でのEXE起動は開発環境では未確認です。** ZIPが生成できたことと、Windows上で動作することは別です。
- Windows 11 x64で、ZIPの全展開・起動・ドラッグ＆ドロップ・日本語保存先・縦横出力・終了を確認してください。
- 初版のアプリは未署名。公開配布のリリース・署名・FFmpegの対応ソース配布はまだ行っていません。
- 現在の制限は250 MB・10分・30fps。長尺や多数チャンネルの音源でのメモリ・性能検証は未実施です。
- GPUエンコード、ジャケット画像、設定保存、60fpsは対象外です。

検証用のスクリーンショットはブラウザが`test-results/`、Electronが`.cache/desktop-test-results/`に出力します（Git対象外）。
テストはローカルで生成した音源を使い、ユーザーの音源を外部に送信しません。
