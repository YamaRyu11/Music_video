Music Video Studio v0.6.0 — Windows x64 ポータブル版

1. ZIP全体を、書き込み可能なフォルダに展開してください。
2. 「Music Video Studio.exe」を起動してください。
3. WAV / MP3をドロップし、全24種類からスタイル・縦横・色・反応を選びます。
   カテゴリと検索でスタイルを絞り込めます。
4. 左のスタイルを合成の01（ベース）・02（重ねる映像）へドラッグして設定します。
   ドラッグを始めると合成タブが開きます。各枠のメニューでも選択できます。
   色・不透明度・合成方法を調整します。
5. 「レイヤー合成 → 背景ビットマップ」で背景画像を選びます。
   画像をウィンドウへドロップして追加することもできます。
   「配置」「トリミング」「エフェクト」を切り替えて編集します。
6. テキストで、タイトル・アーティストの文字サイズ・色・フォント・装飾を編集します。
7. 再生して確認し、「動画を書き出す」で保存先を選びます。

インストール・管理者権限・Node.jsの導入は不要です。
EXEだけを移動せず、resourcesなど同梱ファイルと一緒に保管してください。
実行時の内部データ・キャッシュはEXEと同じフォルダ内のdataに保存されます。
編集した設定や背景画像の保存・次回起動時の復元には対応していません。
音源・背景画像は外部に送信されません。動画生成にインターネット接続は不要です。

ウィンドウ最小サイズは900×640です。画面全体のスクロールはありません。
縦動画では設定を右に配置し、プレビューは比率を保って縮小します。
小さい画面では、設定パネル内だけスクロールする場合があります。

今回の追加スタイル:
Flow Field / Chladni Sand / Moire Weave / Ribbon Helix
ワイヤーフレーム地形やReactive Typographyなど、合計24種類を利用できます。

背景ビットマップ:
PNG / JPEG / WebP / BMP、25 MB・32メガピクセル・各辺16384px以下に対応。
長辺4096pxを超える画像は内部で縮小して使用します。
00の背景画像の上に、01のベース映像・02の重ねる映像・文字を表示します。
拡大率10〜500%、横・縦位置、回転、各辺の切り抜きを調整できます。
ガウスぼかし0〜80px、彩度・明るさ0〜200%、不透明度0〜100%に対応します。
画像の効果は前景や文字とは別々に調整できます。元の画像ファイルは変更しません。

音への反応は最大1000%、動きの滑らかさは最大200%です。
Shiftを押しながらスライダーをドラッグ／矢印キーで、10倍細かく調整できます。
ドラッグ途中でのShift切替と、再生位置のスライダーにも対応しています。

出力: MP4 / H.264 / AAC / 30fps
横: 1920×1080、縦: 1080×1920
音源: WAV / MP3、250 MB以下・10分以内
音声解析・描画・出力には曲の長さに応じた時間とメモリを使用します。
書き出し中はPCをスリープさせず、アプリを開いたままにしてください。

アプリは未署名です。Windows実機での互換性確認は開発状況を参照してください。
FFmpeg等のライセンス情報はresources/THIRD_PARTY.mdを参照してください。
