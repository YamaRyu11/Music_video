Music Video Studio v0.14.0 — Windows x64 ポータブル版

1. ZIP全体を、書き込み可能なフォルダに展開してください。
2. 「Music Video Studio.exe」を起動してください。
3. WAV / MP3をドロップし、全56種類からスタイル・縦横・色・反応を選びます。
   カテゴリと検索でスタイルを絞り込めます。
4. 左のスタイルを画面上部の01（ベース）・02（重ねる映像）へドラッグして設定します。
   各枠のメニューでも選択できます。選択したカードの設定を右に表示します。
   01／02の編集カードを選び、「カラー・動き」でそのレイヤーだけを調整します。
   左の一覧をクリックした際のスタイル適用先も、編集中のレイヤーです。
   01／02のメイン色・サブ色と、01／02それぞれの不透明度・合成方法は右側で設定できます。
5. 上部の00から背景画像を選びます。画像をウィンドウへドロップして追加することもできます。
   細かな調整は右の「背景ビットマップ」の設定、または00の編集ボタンから開き、
   「配置」「トリミング」「エフェクト」を切り替えて編集します。
6. テキストで、タイトル・アーティストの文字サイズ・色・フォント・装飾を編集します。
7. 再生して確認し、「動画を書き出す」で保存先を選びます。

インストール・管理者権限・Node.jsの導入は不要です。
EXEだけを移動せず、resourcesなど同梱ファイルと一緒に保管してください。
実行時の内部データ・キャッシュはEXEと同じフォルダ内のdataに保存されます。
編集した設定や背景画像の保存・次回起動時の復元には対応していません。
音源・背景画像は外部に送信されません。動画生成にインターネット接続は不要です。

ウィンドウ最小サイズは900×640です。画面全体のスクロールはありません。
縦動画では設定を右に配置し、プレビューは比率を保って縮小します。
小さい画面では、設定パネル内だけスクロールする場合があります。
右の設定パネルにタブはなく、選択中のカードの設定を表示します。

スタイル:
Flow Field / Chladni Sand / Moire Weave / Ribbon Helix、
ワイヤーフレーム地形やReactive Typographyなど、合計56種類を利用できます。

01／02ごとの編集:
メイン色・サブ色・明るさ・彩度・光の広がり・音への反応・滑らかさ・線の太さの8項目を、
レイヤーごとに別々に保持します。編集対象は上部のカードと「カラー・動き」の表示で確認できます。
ドロップした先が編集対象になり、Escで取り消した場合はスタイルと編集対象を保持します。
背景色は共通です。パレットは編集中レイヤーのメイン色・サブ色だけを変更します。
上部カードのメイン／サブと、「カラー・動き」のメイン／サブは同じ設定で、変更が同期します。
旧「レイヤーの色」は02のメインカラーと同じ値だったため、メイン／サブの名称へ統一しました。
文字色と背景画像のエフェクトは、それぞれ別の設定です。

線の太さ:
10〜500%、100%が標準です。通常5%刻み、Shiftで0.5%刻みに調整できます。
線の部分へ適用され、粒子や塗りつぶしの大きさは変わりません。
Spectrumは基準線、Chladni Sandは外枠、Reactive Typographyは装飾線、
Liquid Inkは輪郭、Ribbon Helixは縁と連結線が対象です。
Glitch Blocksは面だけのため線幅スライダーは無効です。

リセット:
「カラー・動き」では、選択した01または02の8項目だけを初期化します。
スタイル・02の不透明度と合成方法・共通背景色・他方のレイヤー・文字は保持します。
背景ビットマップを開いている場合は画像の設定だけを初期化し、画像ファイルを保持します。
テキストを開いている場合は選択中の文字デザインだけを初期化し、内容と他方のデザインを保持します。

背景ビットマップ:
PNG / JPEG / WebP / BMP、25 MB・32メガピクセル・各辺16384px以下に対応。
長辺4096pxを超える画像は内部で縮小して使用します。
00の背景画像の上に、01のベース映像・02の重ねる映像・文字を表示します。
拡大率10〜500%、横・縦位置、回転、各辺の切り抜きを調整できます。
ガウスぼかし0〜80px、彩度・明るさ0〜200%、不透明度0〜100%に対応します。
画像の効果は前景や文字とは別々に調整できます。元の画像ファイルは変更しません。

音への反応は最大1000%、動きの滑らかさは最大200%です。
Shiftを押しながらスライダーをドラッグ／矢印キーで、10倍細かく調整できます。
ドラッグ途中でのShift切替と、再生位置のスライダーにも対応しています。

出力: MP4 / H.264 / AAC / 30fps
横: 1920×1080、縦: 1080×1920
音源: WAV / MP3、250 MB以下・10分以内
音声解析・描画・出力には曲の長さに応じた時間とメモリを使用します。
書き出し中はPCをスリープさせず、アプリを開いたままにしてください。

アプリは未署名です。Windows実機での互換性確認は開発状況を参照してください。
FFmpeg等のライセンス情報はresources/THIRD_PARTY.mdを参照してください。


v0.10.0のカード連動編集:

共通背景色はヘッダー左端です。00を選ぶと画像、01／02を選ぶと各映像の設定、03を選ぶと文字の設定を右に表示します。右カラムにタブはありません。
プレビューに表示したタイトル・アーティスト名もクリックして選択できます。非表示の文字は03から選択してください。
01の合成方法・不透明度は背景画像に対して適用し、02はその上に合成します。背景色→画像→01→02→文字の順です。


配色と色の編集（v0.10.0）

「全48配色」から、名前・日本語の説明・種類・検索でメイン／サブの組み合わせを選べます。プリセットは選択中のレイヤーの2色だけに適用し、他方の映像や共通背景色は保持します。明暗差を重視した配色やモノトーンも用意しています。
背景色カードを選ぶと右側に「背景色」を表示し、名前付き32色の背景プリセットを選べます。プリセット一覧はポップアップなので右カラムを縦に増やしません。
ヘッダーや右カラムの色見本をクリックすると、RGB・HEX・HSBをまとめた色パネルが開きます。RGB/HSBの数値は直接入力か上下ドラッグで調整でき、Shiftで10倍細かく動きます。上へドラッグで増加、下で減少です。
Hは色相（0〜360度）、Sは彩度、Bは明度（0〜100%）です。色そのものの明度と、映像全体の明るさは別の設定です。変更は即時反映され、完了・Esc・外側クリックで閉じます。

スタイルのサイズ・位置

01／02を選び「サイズ・位置」を開くと、横／縦の拡大率（10〜500%）と横／縦位置を別々に調整できます。各レイヤーに保存され、MP4出力にも反映します。図形を拡大縮小し、背景画像や独立した文字の位置・大きさは変えません。リセットで拡大率100%・位置中央に戻ります。


v0.11.0の追加機能:

ロック中の拡大率をダブルクリックすると縦横100%に戻り、ロックは維持します。
色パネルのHSBは開いた時点の値へ、再生位置は先頭へ戻ります。
Spectral Waterfall、Phosphor Echo、Radar Pulse、Metaball Field、Fractal Canopy、
Torus Knot、Cellular Bloom、Crystal Shardsを追加し、全32スタイルになりました。


v0.12.0: 線のグローと新8スタイル
カラー・動きのチェックで線のグローをオン・オフできます。
01／02で強さ0〜300%（初期100%）、距離0〜160px（初期24px）を別々に調整します。
距離は出力動画で光がほぼ消えるまでの目安です。文字・背景画像・面の塗りは発光源にしません。
オフでも値を保持。Shiftで微調整、ダブルクリックで初期値へ戻ります。
Harmonic Rose / Pendulum Choir / Gyroid Lattice / Spectral Braid / Harmonic Scope /
Sonar Rings / Woven Ribbons / Orbital Orreryを追加。この版で全40スタイルになりました。


v0.13.0: 透明部分の切替・映像のガウスぼかし・新8スタイル
02は01の上に描画されます。通常100%でも、透明部分や線自身の半透明は残ります。
下を完全に隠す場合は「レイヤーの背景を塗る」をチェックし、通常100%にします。
透明部分は共通背景色で塗ります。初期状態はオフです。
01／02それぞれに映像のガウスぼかし0〜80px（初期0px）を追加しました。
出力動画のpxを基準に、選択した映像とグローをぼかします。文字と背景画像は独立しています。
クラゲ、波の干渉、黄金角の螺旋、紋章、折り紙、球面の帯、光の計器、六角形の波を追加。
この版で全48スタイルになりました。


v0.14.0: プレビュー操作・書き出し設定・開閉する右カラム・新8スタイル
ヘッダーで編集対象を選び、左ドラッグで移動、右ドラッグで拡大縮小。
Shift＋左で縦／横固定、Shift＋右で現在比率を固定、Escでドラッグを取り消します。
背景画像は均等拡大率、文字は文字サイズへ連動し、文字の横位置も調整できます。
右カラムのカラー設定・エフェクト・サイズと位置を開閉できます。カードごとに起動中の状態を保持します。
書き出し前に軽量・標準・高品質、CRFまたは平均ビットレート、AAC音質、処理速度を設定できます。
標準はCRF20・AAC256kbps。設定は起動中に保持し、キャンセルでは出力しません。
メビウスの輪、磁力線、光冠、砂時計、歯車、彗星、稲妻、貝殻を追加し、現在は全56スタイルです。
