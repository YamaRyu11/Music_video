# スタイルガイド（全16種類）

左のカテゴリと検索で探せます。全スタイルを01（ベース）・02（重ねる映像）の両方で使用できます。

| スタイル | カテゴリ | 音への反応・見た目 |
| --- | --- | --- |
| Neon Orbit | 発光 | 低音で膨らむネオンリング、高音で細かく変形 |
| Spectrum | ミニマル | 48帯域の周波数の強さで伸びるバー |
| Particle Flow | 有機的 | 粒子の大きさ・広がりが音で変化 |
| Silk Wave | ミニマル | 音量と周波数で揺らぐ、重なり合う波 |
| Pulse Tunnel | 空間 | 低音とアタックで動く、奥行きのある光の枠 |
| Aurora | 有機的 | 音に合わせて広がる、ふた色のリボン |
| Laser Grid | 空間 | 遠近のあるレーザー格子が低音で波打つ |
| Radial Bloom | 幾何学 | 周波数の強さで花びらが開き、中心が輝く |
| Star Drive | 空間 | 星空を進む表現。音量・アタックで光跡が伸びる |
| Liquid Ink | 有機的 | 音で輪郭が変わり、半透明のインクが重なる |
| Prism Kaleidoscope | 幾何学 | 鏡映した幾何学模様がアタックで回転・変形 |
| Contour Landscape | 空間 | 等高線のような丘が低音で隆起する |
| Glitch Blocks | 幾何学 | 周波数で色の断片が明滅し、アタックでずれる |
| Lissajous | ミニマル | 音の特徴量で形が変わる、複雑な線の軌跡 |
| Light Rain | 発光 | 高音で光の雨が増え、低音で波紋が広がる |
| Reactive Typography | タイポグラフィ | タイトルが音量・低音で伸縮し、アタックで移動・発光 |

## 組み合わせ例

- **Laser Grid ＋ Star Drive**：遠近感のある空間。スクリーン合成で星を重ねる。
- **Liquid Ink ＋ Radial Bloom**：有機的な動きと幾何学的な花を重ねる。
- **Contour Landscape ＋ Light Rain**：風景の上に雨と波紋を追加。
- **Glitch Blocks ＋ Reactive Typography**：断片的な動きと音に反応する曲名。
- **Prism Kaleidoscope ＋ Lissajous**：対称模様と細い線を異なる色で重ねる。

まず02の不透明度を30〜50%程度にすると調整しやすくなります。

## テキストと波形の補足

Reactive Typographyはタイトルを動かします。内容・フォント・サイズ・色・位置・表示切替は「テキスト」タブで設定します。
大きな見出しにする場合は、文字サイズを96〜120px、縦位置を45〜50%程度から調整できます。
02に置いた場合は、レイヤーの色・不透明度・合成方法が動くタイトルにも反映されます。アーティスト名は固定表示です。
タイトルを非表示にすると文字は描かれません。空欄の際に代わりの曲名や透かしを追加することはありません。

Lissajousは音量・低音・高音・アタックを使った図形表現です。生のステレオ波形や位相を計測する表示ではありません。
Liquid Inkは流体風のプロシージャル映像です。

各フレームは音の解析結果と時刻から生成するため、シークしてもプレビューと書き出しで同じ動きになります。
