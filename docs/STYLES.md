## 01／02の独立した調整

「カラー・動き」の8項目（メイン色・サブ色・明るさ・彩度・光の広がり・音への反応・滑らかさ・線の太さ）は、
01／02ごとに保持されます。例えば01の地形を落ち着いた青・細い線にし、02の雨を明るい紫・強い反応にできます。
共通背景色は全体で一つです。パレットは編集中のレイヤーの2色だけを変えます。
上部01／02カードのメイン／サブと、右の「カラー・動き」のメイン／サブは同じ設定で同期します。
メインは主な線や図形、サブは補助線やグラデーションなどに使われます。使い分けはスタイルごとに異なります。
旧「レイヤーの色」は02のメインカラーと同じ値だったため、v0.10.0ではメイン／サブへ名称を統一しています。

「カラー・動き」のリセットは選択側の8項目だけを初期化します。
選んだスタイル、02の不透明度・合成方法、共通背景色、他方のレイヤー、文字は保持します。
背景ビットマップのページでは画像設定だけ、文字の設定では選択中の文字デザインだけが対象です。

## 線の太さの適用範囲

線幅は01／02それぞれ10〜500%で指定し、100%が標準の太さです。
通常は5%刻み、Shiftを押したドラッグ／矢印キーでは0.5%刻みになります。
粒子の直径、塗りつぶした面、棒の幅、文字そのものの太さは変更しません。

| スタイル | 線幅が変わる部分 |
| --- | --- |
| 線を描くスタイル全般 | 模様の線部分。粒子や面のサイズは保持 |
| Spectrum | 基準線。周波数バーの幅は保持 |
| Chladni Sand | 外枠。砂粒のサイズは保持 |
| Reactive Typography | 装飾線。文字は文字の設定のサイズ・太字で編集 |
| Liquid Ink | インクの輪郭線。塗りの広がりは保持 |
| Ribbon Helix | リボンの縁と連結線。リボンの面幅は保持 |
| Glitch Blocks | 対象となる線がないため、線幅スライダーは無効 |

## 組み合わせ例

- **Flow Field ＋ Chladni Sand**：流れる線と節線の粒子を異なる色で重ねる。
- **Moire Weave ＋ Ribbon Helix**：細かな干渉模様と立体的なねじれを組み合わせる。
- **Wireframe Journey ＋ Star Drive**：山間を星が流れる風景。スクリーン合成を20〜35%程度から調整。
- **Resonant Orb ＋ Warp Tunnel**：球体とねじれた奥行きを重ねる。
- **Wireframe Metropolis ＋ Light Rain**：ワイヤー都市に光の雨を追加。
- **Laser Grid ＋ Star Drive**：遠近感のある空間。スクリーン合成で星を重ねる。
- **Liquid Ink ＋ Radial Bloom**：有機的な動きと幾何学的な花を重ねる。
- **Contour Landscape ＋ Light Rain**：風景の上に雨と波紋を追加。
- **Glitch Blocks ＋ Reactive Typography**：断片的な動きと音に反応する曲名。
- **Prism Kaleidoscope ＋ Lissajous**：対称模様と細い線を異なる色で重ねる。

まず02の不透明度を30〜50%程度にすると調整しやすくなります。
上部の00には背景ビットマップを追加できます。細かな画像編集は右側の「背景ビットマップ」の設定か00の編集ボタンから開きます。写真をぼかして彩度・明るさを抑えると、上に重ねた線や粒子を見せやすくなります。
背景画像の効果は01／02や文字とは独立しており、写真だけをモノクロにすることもできます。

「音への反応」は0〜1000%、「動きの滑らかさ」は0〜200%です。Shift＋ドラッグまたはShift＋矢印で10倍細かく調整できます。

## テキストと波形の補足

Reactive Typographyはタイトルを動かします。内容・フォント・サイズ・色・位置・表示切替は「テキスト」の設定で設定します。
大きな見出しにする場合は、文字サイズを96〜120px、縦位置を45〜50%程度から調整できます。
02に置いた場合は、02のメインカラー・不透明度・合成方法が動くタイトルにも反映されます。アーティスト名は固定表示です。
タイトルを非表示にすると文字は描かれません。空欄の際に代わりの曲名や透かしを追加することはありません。

Lissajousは音量・低音・高音・アタックを使った図形表現です。生のステレオ波形や位相を計測する表示ではありません。
Liquid Inkは流体風のプロシージャル映像です。Chladni Sandは音の特徴量を使った定在波風の図形で、実際の振動板を計測した表示ではありません。

各フレームは音の解析結果と時刻から生成するため、シークしてもプレビューと書き出しで同じ動きになります。

## Wireframe Journeyの風景

曲全体の帯域バランスやリズムから、谷の曲がり方・山の粗さ・長い尾根の傾向を決めます。左の山は低音寄り、右は中高音寄りの特徴で独立して変わり、アタックで稜線と進む勢いが変化します。

山は世界の位置に固定し、カメラが前へ移動します。描画回数に応じて山を作り直さないため、シークしても同じ場所へ戻れます。同じ時刻の音量が同じでも曲の過去・音色が異なれば別の風景になります。モノラル音源でも左右の山が変化します。


## v0.10.0のカード連動編集

共通背景色はヘッダー左端です。00を選ぶと画像、01／02を選ぶと各映像の設定、03を選ぶと文字の設定を右に表示します。右カラムにタブはありません。
プレビューに表示したタイトル・アーティスト名もクリックして選択できます。非表示の文字は03から選択してください。
01の合成方法・不透明度は背景画像に対して適用し、02はその上に合成します。背景色→画像→01→02→文字の順です。


## 配色と色の編集（v0.10.0）

「全48配色」から、名前・日本語の説明・種類・検索でメイン／サブの組み合わせを選べます。プリセットは選択中のレイヤーの2色だけに適用し、他方の映像や共通背景色は保持します。明暗差を重視した配色やモノトーンも用意しています。
背景色カードを選ぶと右側に「背景色」を表示し、名前付き32色の背景プリセットを選べます。プリセット一覧はポップアップなので右カラムを縦に増やしません。
ヘッダーや右カラムの色見本をクリックすると、RGB・HEX・HSBをまとめた色パネルが開きます。RGB/HSBの数値は直接入力か上下ドラッグで調整でき、Shiftで10倍細かく動きます。上へドラッグで増加、下で減少です。
Hは色相（0〜360度）、Sは彩度、Bは明度（0〜100%）です。色そのものの明度と、映像全体の明るさは別の設定です。変更は即時反映され、完了・Esc・外側クリックで閉じます。

## スタイルのサイズ・位置

01／02を選び「サイズ・位置」を開くと、横／縦の拡大率（10〜500%）と横／縦位置を別々に調整できます。各レイヤーに保存され、MP4出力にも反映します。図形を拡大縮小し、背景画像や独立した文字の位置・大きさは変えません。リセットで拡大率100%・位置中央に戻ります。


## 拡大率のロックと初期値（v0.11.0）

「サイズ・位置」の鍵ボタンで、その時点の横：縦の比率を固定します。横150%・縦80%でロック後、横300%にすると縦160%になります。01／02で独立して保持し、解除しても値は変わりません。片方が10%／500%に達すると、両方がそこで止まります。

スライダーをダブルクリックすると、その項目の初期値へ戻ります。ロック中の拡大率だけは縦横とも100%へ戻し、ロックを保ちます。色パネルのHSBはパネルを開いた時点の各値へ、再生位置は先頭へ戻ります。Shiftによる微調整も引き続き使えます。

## 類似ソフトからの参考

- [projectM](https://github.com/projectM-visualizer/projectm)：MilkDrop由来の、音から数式で作る多彩な映像表現。
- [Butterchurn](https://github.com/jberg/butterchurn)：WebGLでのMilkDrop表現とプリセット運用。

残像と音による幾何学の変形という方向性を参考にしました。外部のソースコード・プリセット・素材は取り込まず、今回の8スタイルは独自実装しています。Phosphor Echoはフレームを蓄積するGPUフィードバックではなく、音の履歴から輪郭を再構築する方式です。シークやMP4でも同じ時刻を再現できます。


## 線のグロー（v0.12.0）

「カラー・動き」の「線のグローを有効にする」をチェックします。01／02で独立して保持し、オフでも値は保持します。初期状態はオフです。

- 強さ：0〜300%。初期値100%。0%は発光なし。
- 距離：0〜160px。初期値24px。光がほぼ消えるまでの距離の目安で、出力動画のpxを基準とします。0pxは発光なし。
- Shift＋ドラッグで微調整、ダブルクリックで各初期値へ戻ります。

線を描いた色で、近くの光と遠くまでぼける光を加算します。線の芯は保ちます。背景画像・文字・面の塗りは発光源にせず、合成方法・不透明度・色補正はそれぞれのレイヤーに従います。通常の「光の広がり」はスタイル固有の演出で、今回の線のグローとは独立しています。

Glitch Blocksは線がないため操作できません。Spectrumは基準線、Particle Flowは軌跡、Chladni Sandは外枠が対象です。フレーム履歴を蓄積せず、プレビュー・シーク・MP4で同じ時刻を再現します。


## 通常合成・透明部分・ガウスぼかし（v0.13.0）

02は01より上に描画されます。「通常・不透明度100%」はレイヤー全体の不透明度であり、図形のない透明部分や線そのものの半透明は残ります。下のレイヤーを完全に隠す場合は、「カラー・動き」で「レイヤーの背景を塗る」をチェックし、通常・100%にします。透明部分にはヘッダー左端の共通背景色を使い、背景色はレイヤーの色補正・ぼかしで変化しません。初期状態はオフです。

01／02それぞれの「映像のガウスぼかし」は0〜80px（初期値0px）。出力動画のpxを基準に、選択した映像とグローをまとめてぼかします。背景画像と文字は別です。Shiftで微調整、ダブルクリックで0pxへ戻ります。

背景を塗ってぼかした場合もフレームの端は不透明です。レイヤーの不透明度は背景と図形をまとめて一度だけ適用し、100%未満では下が透けます。スクリーン・乗算などは背景色を含めたレイヤーをそれぞれの方式で合成します。


## プレビューで配置する（v0.14.0）

ヘッダーで01／02・背景画像・タイトル／アーティストを選び、プレビュー内で操作します。右カラムのスライダーと双方向に連動します。

| 操作 | 結果 |
| --- | --- |
| 左ドラッグ | 上下左右へ移動 |
| Shift＋左ドラッグ | 動かし始めた方向へ縦／横を固定 |
| 右ドラッグ | 横の動きで横拡大率、縦の動きで縦拡大率を調整（右／上で拡大） |
| Shift＋右ドラッグ | 現在の縦横比を維持して拡大縮小 |
| Esc | 進行中のドラッグを取り消す |

縦横比ロックがオンなら、通常の右ドラッグも比率を保ちます。背景画像は均等拡大率、文字は文字サイズを調整します。文字の横位置もスライダーで編集できます。背景色カードは配置操作の対象外です。プレビューの文字をクリックして編集対象を切り替える操作も使えます。

## 開閉する右カラム（v0.14.0）

「カラー設定」「エフェクト」「サイズ・位置」の見出しで開閉します。閉じても値と描画効果を保持し、01／02それぞれの開閉状態を起動中に保持します。エフェクトにはガウスぼかし・線のグロー・スタイル固有の光をまとめています。

## 書き出し前の設定（v0.14.0）

「画質・音質設定」で調整して保存するか、「動画を書き出す」で設定画面を開いて確認してから保存先を選びます。設定は起動中に保持します。形式はMP4、H.264/AAC、FullHD、30fpsです。

- 軽量：CRF25、AAC128kbps、高速。
- 標準：CRF20、AAC256kbps、速い。
- 高品質：CRF17、AAC320kbps、標準速度。
- 詳細：画質優先のCRF14〜30（Shiftで0.1刻み）、または平均1〜50Mbps。AAC128／192／256／320kbps。圧縮速度は4段階。

CRFは小さいほど高画質・大容量です。平均ビットレートの容量表示は音声込みの目安で、実際の容量は変動します。CRF方式の容量は映像の動き・細かさによって変わります。書き出し設定のキャンセルでは出力を開始しません。
