# スタイルガイド（全24種類）

左のカテゴリと検索で探せます。全24スタイルを01（ベース）・02（重ねる映像）の両方で使用できます。
画面上部のレイヤーヘッダーで01／02の編集カードを選ぶと、左の一覧の選択表示とクリック時の適用先が切り替わります。
一覧から上部の枠へドロップした場合は、そのレイヤーが編集対象になります。
選択・ドラッグ・ドロップで右のタブは切り替わりません。Escで取り消すと編集対象とスタイルを保持します。

## 01／02の独立した調整

「カラー・動き」の8項目（メイン色・サブ色・明るさ・彩度・光の広がり・音への反応・滑らかさ・線の太さ）は、
01／02ごとに保持されます。例えば01の地形を落ち着いた青・細い線にし、02の雨を明るい紫・強い反応にできます。
共通背景色は全体で一つです。パレットは編集中のレイヤーの2色だけを変えます。
上部01／02カードのメイン／サブと、右の「カラー・動き」のメイン／サブは同じ設定で同期します。
メインは主な線や図形、サブは補助線やグラデーションなどに使われます。使い分けはスタイルごとに異なります。
旧「レイヤーの色」は02のメインカラーと同じ値だったため、v0.8.0ではメイン／サブへ名称を統一しています。

「カラー・動き」のリセットは選択側の8項目だけを初期化します。
選んだスタイル、02の不透明度・合成方法、共通背景色、他方のレイヤー、文字は保持します。
背景ビットマップのページでは画像設定だけ、テキストタブでは選択中の文字デザインだけが対象です。

## 線の太さの適用範囲

線幅は01／02それぞれ10〜500%で指定し、100%が標準の太さです。
通常は5%刻み、Shiftを押したドラッグ／矢印キーでは0.5%刻みになります。
粒子の直径、塗りつぶした面、棒の幅、文字そのものの太さは変更しません。

| スタイル | 線幅が変わる部分 |
| --- | --- |
| 線を描くスタイル全般 | 模様の線部分。粒子や面のサイズは保持 |
| Spectrum | 基準線。周波数バーの幅は保持 |
| Chladni Sand | 外枠。砂粒のサイズは保持 |
| Reactive Typography | 装飾線。文字はテキストタブのサイズ・太字で編集 |
| Liquid Ink | インクの輪郭線。塗りの広がりは保持 |
| Ribbon Helix | リボンの縁と連結線。リボンの面幅は保持 |
| Glitch Blocks | 対象となる線がないため、線幅スライダーは無効 |

## 組み合わせ例

- **Flow Field ＋ Chladni Sand**：流れる線と節線の粒子を異なる色で重ねる。
- **Moire Weave ＋ Ribbon Helix**：細かな干渉模様と立体的なねじれを組み合わせる。
- **Wireframe Journey ＋ Star Drive**：山間を星が流れる風景。スクリーン合成を20〜35%程度から調整。
- **Resonant Orb ＋ Warp Tunnel**：球体とねじれた奥行きを重ねる。
- **Wireframe Metropolis ＋ Light Rain**：ワイヤー都市に光の雨を追加。
- **Laser Grid ＋ Star Drive**：遠近感のある空間。スクリーン合成で星を重ねる。
- **Liquid Ink ＋ Radial Bloom**：有機的な動きと幾何学的な花を重ねる。
- **Contour Landscape ＋ Light Rain**：風景の上に雨と波紋を追加。
- **Glitch Blocks ＋ Reactive Typography**：断片的な動きと音に反応する曲名。
- **Prism Kaleidoscope ＋ Lissajous**：対称模様と細い線を異なる色で重ねる。

まず02の不透明度を30〜50%程度にすると調整しやすくなります。
上部の00には背景ビットマップを追加できます。細かな画像編集は右側の「背景ビットマップ」タブか00の編集ボタンから開きます。写真をぼかして彩度・明るさを抑えると、上に重ねた線や粒子を見せやすくなります。
背景画像の効果は01／02や文字とは独立しており、写真だけをモノクロにすることもできます。

「音への反応」は0〜1000%、「動きの滑らかさ」は0〜200%です。Shift＋ドラッグまたはShift＋矢印で10倍細かく調整できます。

## テキストと波形の補足

Reactive Typographyはタイトルを動かします。内容・フォント・サイズ・色・位置・表示切替は「テキスト」タブで設定します。
大きな見出しにする場合は、文字サイズを96〜120px、縦位置を45〜50%程度から調整できます。
02に置いた場合は、02のメインカラー・不透明度・合成方法が動くタイトルにも反映されます。アーティスト名は固定表示です。
タイトルを非表示にすると文字は描かれません。空欄の際に代わりの曲名や透かしを追加することはありません。

Lissajousは音量・低音・高音・アタックを使った図形表現です。生のステレオ波形や位相を計測する表示ではありません。
Liquid Inkは流体風のプロシージャル映像です。Chladni Sandは音の特徴量を使った定在波風の図形で、実際の振動板を計測した表示ではありません。

各フレームは音の解析結果と時刻から生成するため、シークしてもプレビューと書き出しで同じ動きになります。

## Wireframe Journeyの風景

曲全体の帯域バランスやリズムから、谷の曲がり方・山の粗さ・長い尾根の傾向を決めます。左の山は低音寄り、右は中高音寄りの特徴で独立して変わり、アタックで稜線と進む勢いが変化します。

山は世界の位置に固定し、カメラが前へ移動します。描画回数に応じて山を作り直さないため、シークしても同じ場所へ戻れます。同じ時刻の音量が同じでも曲の過去・音色が異なれば別の風景になります。モノラル音源でも左右の山が変化します。
