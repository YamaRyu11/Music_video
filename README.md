# Music Video Studio

WAV / MP3 から、音に反応するフルHD動画をつくるWindows向けデスクトップアプリ。
**ZIPを展開してEXEを起動する、インストール不要のフォルダ型ポータブル版**です。

## v0.11.0 の機能

- 現在の縦横比で固定するロック。01／02それぞれで保持
- スライダーのダブルクリックで各初期値へ復帰
- Spectral Waterfall / Phosphor Echo / Radar Pulse / Metaball Field / Fractal Canopy / Torus Knot / Cellular Bloom / Crystal Shardsを追加

- 名前と説明で選べる48配色・32背景色のプリセット（一覧はポップアップ）
- RGB／HEX／HSBの共通色パネルと、数値の上下ドラッグ調整
- スタイルごとの横・縦拡大率と位置の独立調整

- 音源のドラッグ＆ドロップ・ファイル選択・オリジナルのサンプル音源
- 音量（RMS）・アタック（スペクトルの立ち上がり）・48帯域の周波数解析
- 全32スタイル。Flow Field / Chladni Sand / Moire Weave / Ribbon Helixなどを収録
- 横1920×1080 / 縦1080×1920、30fps
- カテゴリ（ミニマル・発光・幾何学・有機的・空間・タイポグラフィ・ワイヤーフレーム）とスタイル名・説明での検索
- 全体スクロールなしのカラム型ワークスペース。プレビューは比率を保って可変サイズ、縦動画は設定を右に配置
- 01／02でメイン色・サブ色・明るさ・彩度・光の広がり・音への反応・滑らかさ・線の太さを個別調整
- 上部に共通背景色・00の背景画像・01／02のスタイルと2色・03の文字選択を常設。選択カードの設定が右側に連動
- 右側は選択カードに連動する設定パネル。00は画像、01／02はカラー・動き、03は文字を表示
- 01／02の編集カードと左のスタイル一覧が連動。選択したレイヤーだけへスタイルを適用
- 背景色は全体で共通。パレットは選択中レイヤーのメイン色・サブ色だけを変更
- 音への反応は0〜1000%、動きの滑らかさは0〜200%、線の太さは10〜500%。Shift＋ドラッグ／Shift＋矢印キーで10倍細かな調整
- 2つの映像スタイルを重ねて合成。左のスタイルを01（ベース）・02（重ねる映像）へドラッグ＆ドロップ。色・不透明度と、通常／スクリーン／加算／乗算を選択
- 背景ビットマップを00レイヤーに配置。拡大縮小・位置・回転・切り抜き、ガウスぼかし・彩度・明るさ・不透明度を編集
- タイトル・アーティストの文字を別々に編集。サイズ・色・フォント・太字・斜体・揃え・縦位置・影・表示切替
- 音声付きMP4（H.264 / yuv420p / AAC）出力、進捗・キャンセル
- オフラインで動作。音源・背景画像は外部に送信しません

音源は250 MB以下・10分以内。GPUエンコード、60fps、設定の保存は現在の版には含みません。

ウィンドウ最小サイズは900×640です。小さいウィンドウでは設定パネルだけが必要に応じてスクロールし、プレビュー・再生・書き出しは画面内に残ります。

## 開発

Node.js 22.12以降（この環境では24）とnpmを使用します。

```sh
npm ci
npm run dev
```

`npm run dev` はViteとElectronを起動します。デスクトップの起動にはGUIセッションが必要です。
メインプロセス・preloadの変更後は再起動してください。React画面の変更は自動反映されます。

GUIのない環境で画面だけを確認する場合:

```sh
npm run dev:web
```

ブラウザ版は音源解析・プレビュー専用です。MP4出力はElectron版で利用できます。

プロキシ環境でElectronの取得に失敗する場合は、既存のプロキシを維持して
`ELECTRON_GET_USE_PROXY=1 npm ci` を使用します。TLS・チェックサム検証を無効にしないでください。

- 背景画像操作テスト: PNG / JPEG / WebP / BMP、切り抜き・配置・ぼかし・彩度・明るさ・不透明度、表示切替と不正な画像の処理をCanvasの画素で検査します。

- Chromiumは標準で`/usr/bin/chromium`を使用します。別の環境では`CHROMIUM_PATH`に実行ファイルを指定してください。
- デスクトップ操作テスト: Electron本体から縦横のフルHD動画を生成し、音声・映像・フレーム数・長さを検査。合成と90pxの太字・斜体のピンクの文字を含めて書き出し、文字色の画素も検査します。キャンセル時の一時ファイル削除と既存ファイル保持も確認します。GUIセッションと`ffprobe`、検証用の`ffmpeg`が必要です。
- 新スタイル実出力テスト: 追加10種すべてを別の新スタイルと合成し、各1秒・30フレームのフルHD MP4を出力。映像・音声の形式と最終フレームのデコードを検査します。
- ワイヤーフレーム検査: 4種すべての合成MP4出力に加え、曲履歴の違い・左右の山の独立反応・シーク時の世界座標固定を確認します。
- 背景画像の実出力テスト: 縦横2件で元画像の転送・切り抜き・Gaussianぼかし・彩度・明るさを検査。MP4から復号した背景画素がプレビューと一致し、前景の文字色が保たれることを確認します。
- 新4種の実出力テスト: Flow Field / Chladni Sand / Moire Weave / Ribbon Helixを反応1000%・滑らかさ200%で合成し、フルHDのMP4を出力します。
- GUIのないLinux CIではXorgのダミー画面やXvfbを使用し、必要な場合だけ`STUDIO_TEST_NO_SANDBOX=1`を指定します。製品版のサンドボックスは有効です。

## Windows x64 のZIPを作る

### ブラウザからダウンロード

クラウド内の`/workspace/...`へのリンクは、PCへ保存できるダウンロードURLではありません。
GitHubでこのリポジトリの **Actions → Windows portable build → 成功した実行** を開き、
画面下部の **Artifacts → MusicVideoStudio-0.11.0-Windows-x64** をクリックしてください。
GitHubへのログインが必要です。成果物の保存期間は30日です。
期限が切れた場合は **Run workflow** で再作成できます。

ダウンロードされたZIPをすべて展開し、`Music Video Studio.exe`を起動します。
このワークフローはビルド成果物をActionsに添付します。GitHub Releaseの公開は行いません。

### 手元でビルド

```sh
npm run dist:win
```

成果物: `release/MusicVideoStudio-0.11.0-Windows-x64.zip`

ElectronとWindows用FFmpegを含めてパッケージングします。Linux上でのクロスビルドにも対応し、
Windows用FFmpegの取得時にはロックファイルのSHA-512を照合します。ビルドは公開・アップロードを行いません。
ZIPを**すべて展開**し、`Music Video Studio.exe`を起動します。アプリフォルダは書き込み可能な場所に置いてください。
設定・キャッシュ用の`data/`がEXEの隣に作られます。

アプリは未署名です。Windows実機での起動・日本語パス・WAV/MP3・両方向の出力確認は配布前に必要です。
実施済みの確認と未確認事項は[検証記録](docs/VALIDATION.md)を参照してください。
公開配布向けのFFmpegソース同梱・ライセンス対応は[第三者コンポーネント](docs/THIRD_PARTY.md)を参照してください。

## 構成

- `src/audio/`: Web Workerでオフライン解析（Hann窓、2048点FFT、60Hz特徴量）。ステレオは各チャンネルのエネルギーを保持。
- `src/workspace.css`: ウィンドウ内に収まる可変カラム・プレビュー・パネル内スクロール。
- `src/components/LayerToolbar.tsx`: 常設する00／01／02、スタイル・2色・合成方法・不透明度の操作。
- `src/components/Customizer.tsx`: カラー・動き、背景ビットマップ、テキストの編集UI。
- `src/components/BitmapPanel.tsx`: 背景画像の配置・トリミング・エフェクト編集。
- `src/components/Slider.tsx`: キーボード・ポインター操作とShift微調整に対応するスライダー。
- `src/visuals/bitmap.ts`: 画像の読み込み・切り抜き・フィルタと加工結果のキャッシュ。
- `src/visuals/`: Canvas 2Dによる描画。時間とシードから決まるため、シーク・プレビュー・出力で再現可能。
- `src/render-worker.ts`: 非表示のElectronウィンドウで、各フレームを正確な時刻に描画。
- `electron/`: ファイル選択、制限付きIPC、FFmpegへのバックプレッシャー付きフレーム送信、出力管理。
- `scripts/`: 開発起動、ビルド、サンプル音源生成、Windows依存ファイル準備。

WebGLではなくCanvas 2Dを初版で採用しています。フレームはJPEG品質97%でFFmpegへ渡すため、
中間処理は非可逆です。プレビューは縮小描画、出力はフルHD。描画負荷が高くても映像の時刻は音源に同期します。
書き出しは一時ファイルへ行い、正常完了後に保存先へ移動します。キャンセル時は一時ファイルを削除します。

各スタイルの特徴と合成例は[スタイルガイド](docs/STYLES.md)を参照してください。

## レイヤーごとの色・動き

画面上部のレイヤーヘッダーで01（ベース）または02（重ねる映像）の編集カードを選び、
右側に「カラー・動き」を表示します。「レイヤー01を編集中」「レイヤー02を編集中」の表示を確認して調整してください。

次の8項目は01／02がそれぞれ保持し、他方の設定を変えずに編集できます。

- メインカラー・サブカラー
- 明るさ・彩度・光の広がり
- 音への反応・動きの滑らかさ
- 線の太さ（10〜500%、100%が標準）

左の一覧の選択表示とクリック時の適用先も、編集中の01／02へ切り替わります。
スタイルを上部の01／02へドロップすると、そのレイヤーが編集対象になります。
01／02を選ぶと、そのレイヤーのカラー・動き・合成方法・不透明度を右に表示します。
ドラッグをEscで取り消した場合は、スタイルとそれまでの編集対象を保持します。
スタイルを差し替えても、そのレイヤーの色・動きの値は保持されます。

**背景色は全レイヤーで共通**です。パレット選択は編集中レイヤーのメイン色・サブ色だけを変更し、
共通背景色や他の調整値は保持します。背景ビットマップと文字のデザインも個別に編集できます。

### メインカラー・サブカラーと、旧「レイヤーの色」

上部の01／02カードにあるメイン色・サブ色と、「カラー・動き」の2色は同じ設定です。
どちらで編集しても同期します。メイン色は主な線や図形、サブ色は補助線・グラデーション・別のパーツなどに使われ、使い分けはスタイルによって異なります。

旧画面の「レイヤーの色」は02のメインカラーと同じ値でした。v0.10.0では名称をメイン／サブへ統一しました。
共通背景色、タイトル・アーティストの文字色、背景画像のエフェクトは、それぞれ別の設定です。

### 線の太さ

線の太さは線を描く部分へ適用され、粒子の大きさや塗りつぶした面の大きさは変えません。
Spectrumでは基準線、Chladni Sandでは外枠、Reactive Typographyでは装飾線、
Liquid Inkでは輪郭、Ribbon Helixでは縁と連結線が対象です。
Glitch Blocksは面で構成するため線幅調整に対応せず、スライダーは無効になります。
詳細は[スタイルガイド](docs/STYLES.md#線の太さの適用範囲)を参照してください。

## リセットの対象

画面上のリセットは、開いている編集項目に応じて次の範囲へ適用されます。

| 開いている編集項目 | 初期値へ戻すもの | 保持するもの |
| --- | --- | --- |
| カラー・動き | 編集中の01または02の8項目 | スタイル・不透明度・合成方法・共通背景色・他方のレイヤー・背景画像・文字 |
| 背景ビットマップ | 画像の配置・切り抜き・効果・表示設定 | 読み込んだ画像ファイル・01／02・文字 |
| テキスト | 編集中のタイトルまたはアーティストのデザイン | 文字の内容・他方の文字デザイン・01／02・背景画像 |

## 背景ビットマップの編集

画面上部の00から背景画像を選ぶか、PNG / JPEG / WebP / BMPをウィンドウへドロップします。
細かな調整は右側の「背景ビットマップ」の設定で行います。上部00の編集ボタンからも開けます。
00の背景画像、01のベース映像、02の重ねる映像、文字の順で表示します。

- **配置**: 画像全体を収める／画面を埋める、拡大率10〜500%、横・縦位置、回転を調整。
- **トリミング**: 各辺から切り抜く量を指定。左右・上下それぞれの合計は95%までで、画像の領域を残します。元の画像ファイルは変更しません。
- **エフェクト**: ガウスぼかし0〜80px、彩度・明るさ0〜200%、不透明度0〜100%。ぼかしのpxは出力動画の寸法を基準とします。
- **表示・削除・リセット**: 一時的に非表示にする、画像を削除する、画像を保って配置・効果を初期値へ戻すことができます。画像の差し替え時には配置・効果が初期値へ戻ります。

対応画像は25 MB・32メガピクセル・各辺16384px以下です。長辺が4096pxを超える画像は内部で縮小して保持します。
背景画像の効果は前景のスタイルや文字から独立しており、ガウスぼかしやモノクロ化を文字へかけずに背景だけを加工できます。

## スライダーの微調整

通常のドラッグと矢印キーで調整し、**Shiftを押しながらドラッグ／矢印キー**で10倍細かく動かせます。
ドラッグの途中でもShiftを押す／離すことで調整速度を切り替えられます。再生位置のスライダーも対応しています。
「音への反応」は1000%、「動きの滑らかさ」は200%、「線の太さ」は500%まで調整できます。
線の太さは通常5%刻み、Shift使用時は0.5%刻みで調整します。100%が従来の太さです。

## 音楽で変わるワイヤー地形

「ワイヤーフレーム」カテゴリの **Wireframe Journey** は、中央の曲がる谷を進む擬似3D映像です。左の山は低音寄り、右の山は中高音寄りの帯域に対応し、音の立ち上がりが稜線や移動の勢いに影響します。

曲全体の音色・リズムの特徴から地形の傾向を決め、音声の履歴を空間へ対応させます。名前を変えても同じ音源なら同じ風景になり、同じ曲の同じ時刻へシークすると同じ位置へ戻ります。左右の対応はステレオのL/Rチャンネル分離ではありません。

「音への反応」で山の変化量、「メインカラー」「サブカラー」で左右の線の色を調整できます。

## 編集のヒント

- **スタイル探し**: カテゴリと検索を使って絞り込みます。一覧のスクロールは左カラムの中だけで行われます。
- **ワークスペース**: 上部にレイヤー操作を常設し、スタイル一覧・プレビュー・設定を分割。プレビューの比率を保って空間へ収めます。画面全体はスクロールせず、必要な場合だけ設定パネル内をスクロールします。
- **カラー・動き**: 01／02の編集対象を確認して、2色・明るさ・彩度・動き・線幅を調整します。背景色は共通です。
- **上部のレイヤー操作**: 左の一覧から01（ベース）・02（重ねる映像）の枠へドラッグします。各枠の選択メニューでも設定でき、ドロップ先が編集対象になります。操作中も右のタブは維持します。不透明度・合成方法は02の合成設定です。0%または「なし」で合成を解除できます。
- **背景ビットマップ**: 上部00で画像を選び、右の「背景ビットマップ」で「配置」「トリミング」「エフェクト」を切り替えて編集します。このタブを開いたまま、上部01／02へスタイルをドロップできます。
- **テキスト**: ファイル名から自動入力されたタイトルを自由に変更できます。「タイトルのデザイン」と「アーティストのデザイン」を切り替えて編集します。サイズは出力動画でのpx、縦位置は画面の上からの割合です。
- 01／02それぞれの色・動き、背景画像のエフェクト、文字のデザインは別々に設定できます。
- フォントはPCにあるフォントを使用し、未インストールの場合は代替されます。カスタムフォントの取り込みは未対応です。
- リセットは編集中の対象にだけ適用されます。詳しくは「リセットの対象」を参照してください。

## Git

通常は`main`から`feat/...`や`fix/...`を切り、検証後にコミット・マージします。
生成物・依存ファイル・テスト出力はGitの対象外です。ZIPはGitにコミットしません。
クラウドタスクは既に分離された環境なので、通常は既存チェックアウトで作業し、worktreeは作成しません。


## v0.10.0のカード連動編集

共通背景色はヘッダー左端です。00を選ぶと画像、01／02を選ぶと各映像の設定、03を選ぶと文字の設定を右に表示します。右カラムにタブはありません。
プレビューに表示したタイトル・アーティスト名もクリックして選択できます。非表示の文字は03から選択してください。
01の合成方法・不透明度は背景画像に対して適用し、02はその上に合成します。背景色→画像→01→02→文字の順です。


## 配色と色の編集（v0.10.0）

「全48配色」から、名前・日本語の説明・種類・検索でメイン／サブの組み合わせを選べます。プリセットは選択中のレイヤーの2色だけに適用し、他方の映像や共通背景色は保持します。明暗差を重視した配色やモノトーンも用意しています。
背景色カードを選ぶと右側に「背景色」を表示し、名前付き32色の背景プリセットを選べます。プリセット一覧はポップアップなので右カラムを縦に増やしません。
ヘッダーや右カラムの色見本をクリックすると、RGB・HEX・HSBをまとめた色パネルが開きます。RGB/HSBの数値は直接入力か上下ドラッグで調整でき、Shiftで10倍細かく動きます。上へドラッグで増加、下で減少です。
Hは色相（0〜360度）、Sは彩度、Bは明度（0〜100%）です。色そのものの明度と、映像全体の明るさは別の設定です。変更は即時反映され、完了・Esc・外側クリックで閉じます。

## スタイルのサイズ・位置

01／02を選び「サイズ・位置」を開くと、横／縦の拡大率（10〜500%）と横／縦位置を別々に調整できます。各レイヤーに保存され、MP4出力にも反映します。図形を拡大縮小し、背景画像や独立した文字の位置・大きさは変えません。リセットで拡大率100%・位置中央に戻ります。


## 拡大率ロックと初期値（v0.11.0）

「カラー・動き」→「サイズ・位置」の鍵で、現在の横：縦の比率を固定します。横150%・縦80%なら、横300%への変更で縦160%になります。01／02それぞれで保持し、10%／500%では両方が一緒に止まります。

スライダーはダブルクリックで項目ごとの初期値へ戻ります。ロック中の拡大率は縦横100%へ戻り、ロックを保ちます。HSBは色パネルを開いた値へ、再生位置は先頭へ戻ります。Shiftでの微調整も使えます。
