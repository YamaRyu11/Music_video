# Music Video Studio

WAV / MP3 から、音に反応するフルHD動画をつくるWindows向けデスクトップアプリ。
**ZIPを展開してEXEを起動する、インストール不要のフォルダ型ポータブル版**です。

## v0.3.0 の機能

- 音源のドラッグ＆ドロップ・ファイル選択・オリジナルのサンプル音源
- 音量（RMS）・アタック（スペクトルの立ち上がり）・48帯域の周波数解析
- Neon Orbit / Spectrum / Particle Flow / Silk Wave / Pulse Tunnel / Aurora の6スタイル
- 横1920×1080 / 縦1080×1920、30fps
- 全体スクロールなしのカラム型ワークスペース。プレビューは比率を保って可変サイズ、縦動画は設定を右に配置
- メイン色・サブ色・背景色、明るさ・彩度・光の広がり、反応の強さ・滑らかさの調整
- 2つの映像スタイルを重ねて合成。左のスタイルを01（ベース）・02（重ねる映像）へドラッグ＆ドロップ。色・不透明度と、通常／スクリーン／加算／乗算を選択
- タイトル・アーティストの文字を別々に編集。サイズ・色・フォント・太字・斜体・揃え・縦位置・影・表示切替
- 音声付きMP4（H.264 / yuv420p / AAC）出力、進捗・キャンセル
- オフラインで動作。音源は外部に送信しません

音源は250 MB以下・10分以内。ジャケット画像、GPUエンコード、60fps、設定の保存は現在の版には含みません。

ウィンドウ最小サイズは900×640です。小さいウィンドウでは設定パネルだけが必要に応じてスクロールし、プレビュー・再生・書き出しは画面内に残ります。

## 開発

Node.js 22.12以降（この環境では24）とnpmを使用します。

```sh
npm ci
npm run dev
```

`npm run dev` はViteとElectronを起動します。デスクトップの起動にはGUIセッションが必要です。
メインプロセス・preloadの変更後は再起動してください。React画面の変更は自動反映されます。

GUIのない環境で画面だけを確認する場合:

```sh
npm run dev:web
```

ブラウザ版は音源解析・プレビュー専用です。MP4出力はElectron版で利用できます。

プロキシ環境でElectronの取得に失敗する場合は、既存のプロキシを維持して
`ELECTRON_GET_USE_PROXY=1 npm ci` を使用します。TLS・チェックサム検証を無効にしないでください。

## 検証

```sh
npm run typecheck
npm test
npm run build
npm run test:e2e
npm run test:desktop
```

- ユニットテスト: FFTの周波数検出、無音、音量差、アタック、位相反転ステレオ、IPC入力検証。
- エンコードテスト: 同梱FFmpegで実際に生成したMP4を`ffprobe`で検査します。開発機には`ffprobe`を用意してください。
- ブラウザ操作テスト: 音源読み込み・再生・シーク・6スタイル・縦横切替・色調整・合成・文字編集・不正ファイルの処理。透明度0の合成はベースと画素が同じになることも検査します。
- Chromiumは標準で`/usr/bin/chromium`を使用します。別の環境では`CHROMIUM_PATH`に実行ファイルを指定してください。
- デスクトップ操作テスト: Electron本体から縦横のフルHD動画を生成し、音声・映像・フレーム数・長さを検査。合成と90pxの太字・斜体のピンクの文字を含めて書き出し、文字色の画素も検査します。キャンセル時の一時ファイル削除と既存ファイル保持も確認します。GUIセッションと`ffprobe`、検証用の`ffmpeg`が必要です。
- GUIのないLinux CIではXorgのダミー画面やXvfbを使用し、必要な場合だけ`STUDIO_TEST_NO_SANDBOX=1`を指定します。製品版のサンドボックスは有効です。

## Windows x64 のZIPを作る

### ブラウザからダウンロード

クラウド内の`/workspace/...`へのリンクは、PCへ保存できるダウンロードURLではありません。
GitHubでこのリポジトリの **Actions → Windows portable build → 成功した実行** を開き、
画面下部の **Artifacts → MusicVideoStudio-0.3.0-Windows-x64** をクリックしてください。
GitHubへのログインが必要です。成果物の保存期間は30日です。
期限が切れた場合は **Run workflow** で再作成できます。

ダウンロードされたZIPをすべて展開し、`Music Video Studio.exe`を起動します。
このワークフローはビルド成果物をActionsに添付します。GitHub Releaseの公開は行いません。

### 手元でビルド

```sh
npm run dist:win
```

成果物: `release/MusicVideoStudio-0.3.0-Windows-x64.zip`

ElectronとWindows用FFmpegを含めてパッケージングします。Linux上でのクロスビルドにも対応し、
Windows用FFmpegの取得時にはロックファイルのSHA-512を照合します。ビルドは公開・アップロードを行いません。
ZIPを**すべて展開**し、`Music Video Studio.exe`を起動します。アプリフォルダは書き込み可能な場所に置いてください。
設定・キャッシュ用の`data/`がEXEの隣に作られます。

アプリは未署名です。Windows実機での起動・日本語パス・WAV/MP3・両方向の出力確認は配布前に必要です。
実施済みの確認と未確認事項は[検証記録](docs/VALIDATION.md)を参照してください。
公開配布向けのFFmpegソース同梱・ライセンス対応は[第三者コンポーネント](docs/THIRD_PARTY.md)を参照してください。

## 構成

- `src/audio/`: Web Workerでオフライン解析（Hann窓、2048点FFT、60Hz特徴量）。ステレオは各チャンネルのエネルギーを保持。
- `src/workspace.css`: ウィンドウ内に収まる可変カラム・プレビュー・パネル内スクロール。
- `src/components/Customizer.tsx`: 色・動き、レイヤー合成、テキストの編集UI。
- `src/visuals/`: Canvas 2Dによる描画。時間とシードから決まるため、シーク・プレビュー・出力で再現可能。
- `src/render-worker.ts`: 非表示のElectronウィンドウで、各フレームを正確な時刻に描画。
- `electron/`: ファイル選択、制限付きIPC、FFmpegへのバックプレッシャー付きフレーム送信、出力管理。
- `scripts/`: 開発起動、ビルド、サンプル音源生成、Windows依存ファイル準備。

WebGLではなくCanvas 2Dを初版で採用しています。フレームはJPEG品質97%でFFmpegへ渡すため、
中間処理は非可逆です。プレビューは縮小描画、出力はフルHD。描画負荷が高くても映像の時刻は音源に同期します。
書き出しは一時ファイルへ行い、正常完了後に保存先へ移動します。キャンセル時は一時ファイルを削除します。

## 編集のヒント

- **ワークスペース**: スタイル一覧・プレビュー・設定を分割。縦動画では設定を右に配置し、狭い横動画のウィンドウでは設定を下段に配置します。画面全体はスクロールせず、必要な場合だけ設定パネル内をスクロールします。
- **カラー・動き**: パレットを選び、メイン色・サブ色・背景、明るさ・彩度などを調整します。
- **レイヤー合成**: 左の一覧から01（ベース）・02（重ねる映像）の枠へドラッグします。ドラッグ開始で合成タブが自動的に開きます。各枠の選択メニューでも設定できます。重ねるスタイルの色・不透明度・合成方法を設定します。0%または「なし」で合成を解除できます。
- **テキスト**: ファイル名から自動入力されたタイトルを自由に変更できます。「タイトルのデザイン」と「アーティストのデザイン」を切り替えて編集します。サイズは出力動画でのpx、縦位置は画面の上からの割合です。
- 色調整は映像に適用し、テキストの色は個別指定したものを保ちます。
- フォントはPCにあるフォントを使用し、未インストールの場合は代替されます。カスタムフォントの取り込みは未対応です。
- リセットでは文字の内容・スタイル選択・動画の向きを保ち、色・合成・文字デザインを初期値に戻します。

## Git

通常は`main`から`feat/...`や`fix/...`を切り、検証後にコミット・マージします。
生成物・依存ファイル・テスト出力はGitの対象外です。ZIPはGitにコミットしません。
クラウドタスクは既に分離された環境なので、通常は既存チェックアウトで作業し、worktreeは作成しません。
